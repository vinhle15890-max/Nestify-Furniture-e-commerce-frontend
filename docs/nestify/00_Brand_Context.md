# Nestify Brand Context v0.1

# Project Positioning

**Business**
- Furniture e-commerce website.

**Brand**
- Empower users to confidently shape their own living space before purchasing.

---

# Core Insight

Current furniture websites mainly display products.

Users still wonder:
- Will it fit?
- Will it look good?
- Did I choose correctly?

Nestify reduces uncertainty by letting users visualize and experiment before making a decision.

---

# Core User Journey

Before visiting:
> "What should I put in my home?"

↓

Discover Nestify

↓

Experiment with furniture

↓

Visualize the future home

↓

Gain confidence

↓

Purchase

After leaving:
> "Now I know what my home will look like."

---

# Emotional Goal

Primary emotion:
- Ownership

Meaning:
- The user owns every design decision.
- The home reflects the person living in it.

---

# Brand Belief

Every home should reflect the person who lives in it.

Nestify should never dictate how a home should look.
Instead, it provides the tools for users to explore, experiment, and decide.

---

# Brand Purpose

Help people confidently make furnishing decisions by allowing them to visualize and test ideas before buying.

---

# Brand Personality

Nestify is:

- A guide
- Calm
- Helpful
- Inspiring
- Never pushy
- Never acts like a salesperson

Nestify says:
"Let's see how it looks in your space."

Instead of:
"Buy this product."

---

# Differentiation

Not:
- Just another furniture store
- Just another product catalog
- Just a 3D feature

Instead:

A furniture store that helps people confidently create the home they imagine.

---

# Main Character

The main character is NOT the 3D Room Planner.

The main character is the user.

The planner is only the tool that helps the user realize their vision.

---

# Story Flow

Chapter 1
An empty space.

Question:
"What should I add to my home?"

Chapter 2
Discover possibilities.

Chapter 3
Experiment freely.

Chapter 4
See the future home.

Chapter 5
Feel ownership.

Chapter 6
Purchase with confidence.

---

# Design Principle

Every UI decision should answer:

"Does this help users imagine, experiment, or decide?"

If not, it should be reconsidered.

---

# Things Nestify Should Avoid

- Looking like a generic furniture marketplace
- Aggressive sales language
- Product-first storytelling
- Flash-sale aesthetics
- Making the 3D Planner feel like a gimmick

# R2 Model Diagnostic — Visual Frame Brief

## Surface

- Route: `/__dev/r2-model`; development-only internal diagnostic.
- Type: Capability Boundary evidence surface associated with State 3, not a new Planner state.
- Intent: determine whether one public GLB crosses browser delivery and loader boundaries.
- Authority consulted: Nestify canonical `01` through `05`; D-001 checked and not in conflict.

## Hierarchy and composition

- First target: the real rendered sofa, winning through canvas scale and spatial depth.
- Second target: compact evidence panel; URL input is tertiary.
- Dominant mass: asymmetric 3D viewport. Counterweight: narrow evidence rail.
- Quiet zone: clear canvas area around the object, used to judge silhouette and fallback substitution.
- Not a 50:50 split: viewport owns all remaining width; evidence stays at 20rem.

## Visual grammar

- Low-density, functional diagnostic. Illustration/photography have no role.
- Line: grid is measurement context, not decoration; panel divider is subordinate.
- Depth: camera perspective, object occlusion, grid recession, and directional light.
- Light: one upper-side directional source makes model volume readable.
- Deliberate asymmetry: evidence rail occupies one edge rather than centering over the model.
- Wide/desktop: viewport remains primary. Narrow: viewport precedes evidence; this route does not claim Planner small-screen support.
- Forbidden: sales styling, decorative CAD fiction, product cards, Committed color, or fallback presented as success.
- AI smells: no gratuitous cards, pills, gradients, fake metrics, or ornamental geometry.

## Review handoff

- Required evidence: supported desktop from origin `http://localhost:1309`, normal/grayscale/silhouette key frame, plus failure states.
- Open assumption: no visual verdict is possible until a real public R2 URL and browser run exist.
